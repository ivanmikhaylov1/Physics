# Моделирование качение шара

Этот проект моделирует качение шара по наклонной плоскости в 1D случае и произвольное
качение по плоскости в 2D случае. 

---
## ## 1. Установка и использование

### Шаг 1. Клонировать проект

```bash
git clone https://github.com/username/project-name.git
```

### Шаг 2. Создать и активировать виртуальное окружение

**Windows PowerShell:**

```powershell
python -m venv venv
.\venv\Scripts\Activate
```

**Linux/macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4. Настроить параметры моделирования

Параметры задаются в файле `params.json`, эталонные json:

Для качание по наклонной:
```json
{
  "mode": "incline",
  "ball": {
    "mass": 0.2,
    "radius": 0.05,
    "hollow": false
  },
  "incline": {
    "angle_deg": 30.0,
    "friction_coeff": 0.25
  }
}
```

Для произвольного качание по плоскости:
```json
{
  "mode": "horizontal",
  "ball": {
    "mass": 1.0,
    "radius": 0.1,
    "hollow": false
  },
  "plane": {
    "friction_coeff": 0.2
  },
  "initial_conditions": {
    "v0": 2.0,
    "theta_v_deg": 0.0,
    "omega0_x": 0.0,
    "omega0_z": -10.0
  }
}
```
Где:

* `model` - тип модели `incline` или `horizontal`
* `mass` - масса мяча [кг]
* `radius` - радиус мяча [м]
* `hollow` - полый ли мяч
* `friction_coeff` - коэффициент трения
* `v0` - начальная скорость [м/с]
* `theta_v_deg` - угол начальной скорости
* `omega0_x` - угловая скорость вокруг оси x [рад/c]
* `omega0_z` - угловая скорость вокруг оси z [рад/c]
* `angle_deg` - угол наклона плоскости

### Шаг 5. Запустить симуляцию

После запуска откроется окно с графиками, которые отображают изменения кординат,
модулей скоростей, кинетических, потенциальныой и полной энергий

### Запустить тесты

После запуска, будет произведено тестирование со случайными параметрами:
1. Без трения
2. С трением

# 2. Теория

## 2.1 Качение и проскальзывание

Второй закон Ньютона $F = m\frac{dv}{dt}$
Уравнение моментов относительно центра $I\frac{dw}{dt} = r\cdot F$

$vrel = v - wr$

Если $|vrel| > 0$ - скольжение $Fтр =  -mu\cdot N$

Если $|vrel| ~= 0$ - качение

В случае наклонной добавляется внешняя сила Fт, её момент равен 0

# 2.2 Численное моделирование
Моделирование происходит по средствам решения системы уравнений методом Эйлера

Модель корректно воспроизводит:
* переход от скольжения к качению
* полную остановку
